# POTKOVICE · CRM

Interni CRM za uvoz i prodaju potkovica, eksera i opreme za potkivanje.

- Aplikacija: GitHub Pages (statična stranica), baza: Supabase (tabele `p_*`).
- Sekcije: Pregled, Beleške, Porudžbine, Kupci, Potkovice, Nabavka i uvoz, Reklamacije, Objave, Sajt, Reklame, Istorija.
- Nabavka i uvoz računa stvarnu nabavnu cenu po komadu (roba + vozarina + carina + ostalo) i prima robu na stanje.
- Asistent (dugme dole desno) radi i bez AI ključa; sa ključem (Supabase tajna `ANTHROPIC_API_KEY`) prelazi u AI režim.
- Pristup: konstantin, marjan, stefan. Podaci drugih projekata nisu dostupni ovom modulu.
